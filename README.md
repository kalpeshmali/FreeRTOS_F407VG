# FreeRTOS_F407VG
Project Based on the RTOS

SWV ITM Data Console 
1. Go to Project -> Window -> Show View -> SWV -> SWV ITM Data Console
2. Go to SWV ITM Data Console -> Configure trace -> ITM Stimulus Ports -> tick 0 port
3. Ok

Build the project using Debug Mode
1. Right Click on the project -> Debug As -> STM32 C/C++ Application
2. Resume (F8)
3. Go to the SWV ITM Data Console and check the messages
